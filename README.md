# Octane-1
Its my series of model rockets. It will have all its simulations, 3d photos, stage dissections, etc.
This is a series of low power rockets. I'll be experimenting quite some bit with the designs and we'll see where this leads us to.

The octane-1 is a 49.6 cm long rocket with a width o 2.48 cm. This rocket uses a D-10W 7 engine
